== Description

This resource connects to an OAuth2 / OpenID Connect authorization server, either to introspect an access token or to
retrieve user info.

It should be able to handle common authorization servers from the market by providing a complete configuration about
the way to apply token introspection.

The configuration comes in two variants:

* *Token introspection (OAuth2)*, used by the `OAuth2` policy to validate an incoming access token. This is the
  configuration described below.
* *UserInfo only (OIDC)*, used by the `OpenID Connect - UserInfo` policy alone, typically when the API is secured by a
  JWT plan. See <<_userinfo_only>>.

[#_userinfo_only]
== UserInfo only

When this resource is only consumed by the `OpenID Connect - UserInfo` policy, no client credentials are needed: the
UserInfo call authenticates with the caller's own access token, and no introspection call is made. Selecting the
*UserInfo only (OIDC)* variant reduces the configuration to the authorization server and the userinfo endpoint:

[source, json]
.UserInfo-only configuration example
----
{
    "configuration": {
        "mode": "USERINFO",
        "authorizationServerUrl": "https://idp.example.com",
        "userInfoEndpoint": "/userinfo",
        "userInfoEndpointMethod": "GET",
        "userClaim": "sub"
    }
}
----

Configurations written before this variant existed do not carry the `mode` field; they keep being read as token
introspection and are unaffected.
